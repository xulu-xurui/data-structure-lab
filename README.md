# 数据结构实验 · 二叉树遍历 AR / VR 演示

《数据结构与算法》实验三（二叉树的建立及遍历）的扩展案例：把二叉树的四种遍历做成**可交互的三维演示**，支持 **AR 叠加** 与 **沉浸式 VR** 两种形态，全部在一个 HTML 文件里，离线可运行。

在线演示：<https://xulu-xurui.github.io/data-structure-lab/>

## 两种场景

| 页面 | 说明 |
|---|---|
| [index.html](https://xulu-xurui.github.io/data-structure-lab/) | 沉浸式遍历演示：站在二叉树里，四种遍历、点节点建树、陀螺仪、立体分屏 |
| [classroom.html](https://xulu-xurui.github.io/data-structure-lab/classroom.html) | **教室 AR 课堂**：站在环绕的教室里，中间是二叉树，四周是知识点卡片，点卡片展开讲解 |

## 一、功能

### 四种遍历
- 先序、中序、后序（非递归，显式栈 + last 标记）、层次遍历（循环队列）
- 单步 / 连续播放，实时显示栈（或队列）内容与已访问序列

### 建树（三种方式，不用记格式）
- 点 **3 / 7 / 15 / 24** 一键生成完全二叉树
- 点 **随机** 生成随机形状的树
- 在场景里**点选任意节点**，直接「加左子节点 / 加右子节点」或删除整棵子树
- 也可以直接输入先序扩展序列（# 表示空）

### 沉浸式三维（VR 方向）
- 第一人称站在二叉树内部，节点悬在四周，拖动环顾、前后走动
- 手机开启**陀螺仪**，转头即看
- **立体分屏**：横屏放进 Cardboard 类纸板盒，得到双目视差
- 属于 VR 的简化形态：沉浸式第一人称场景 + 头部跟踪 + 双目视差；接 VR 头显启用 WebXR 可升级为标准设备体验

### AR 叠加（增强现实方向）
- **AR 摄像头**：摄像头实时画面做背景，三维二叉树叠加其上，画面对位框提示对准报告中的流程图
- **拍照叠加**：拍一张照片（或选相册图片）做背景，三维树叠在上面——不需要摄像头权限，任何环境可用

## 二、怎么打开

| 场景 | 做法 |
|---|---|
| 电脑 | 双击 `index.html`，用 Chrome / Edge 打开 |
| 安卓手机 | 文件管理器长按 → 打开方式 → 浏览器；或浏览器地址栏 `file:///sdcard/Download/index.html` |
| iPhone | 建议部署到 https 后用 Safari 打开，或用 Documents 类 App 打开本地文件 |

> 用 `file://` 打开时，浏览器**禁止调用摄像头**（安全策略，任何代码都绕不过）。此时页面会提示改用「拍照叠加」。

---

## 三、手机用实时摄像头 / 在线访问

浏览器规定：只有 **https** 或 **localhost** 页面才能调用摄像头。把本仓库开启 GitHub Pages 即可：

1. 仓库 → Settings → Pages
2. Source 选 **Deploy from a branch**，分支 **main**，目录 **/(root)**，保存
3. 等约 1 分钟，访问 `https://xulu-xurui.github.io/data-structure-lab/`
4. 手机打开该链接 → 点「AR 摄像头」→ 允许权限

## 四、操作一览

| 操作 | 效果 |
|---|---|
| 拖动 / 手指拖动 | 环顾四周 |
| 滚轮 / 双指捏合 | 前后移动 |
| ↑ ↓ | 前后移动（电脑） |
| 点节点 | 选中，弹出「加左/右子节点」「删除子树」 |
| 点「隐藏面板」 | 全屏观看 |
| 点「立体分屏」 | 左右分屏（Cardboard） |
| 点「陀螺仪」 | 手机转头控制视角 |

## 五、技术说明

- 纯前端单文件，无任何依赖，Canvas 2D 手写三维投影
- 自建透视相机（yaw / pitch / 深度裁剪），节点半径按世界坐标换算，保证任意规模树的显示比例
- 树的布局按**中序序号定 x、深度定 y**，并加轻微 z 抖动，转头时产生视差
- 遍历过程由「事件流 + 快照」驱动，播放时逐步回放，栈/队列状态与页面同步
- 兼容性：全文 ES5 语法，可在老版本 WebView 中运行
